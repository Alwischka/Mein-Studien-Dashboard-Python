# Mein Studien-Dashboard

Dieses Projekt ist mein Dashboarde-Prototyp für mein Studium "Medizinische Informatik"

Dieses Dashboard habe ich im Rahmen des Portfolios im Modul
**"Objektorientierte und funktionale Programmierung mit Python"** entwickelt.

## Funktionen

Mein Dashboard zeigt:

- aktueller Studienfortschritt
- Anzahl abgeschlossener Module
- aktueller Notendurchschnitt
- Studientempo
- Prüfungs- und Abgabefristen

Die Studiendaten speichern sich in einer JSON-Datei und werden beim Start des Programms geladen.

## Projektdateien

- 'Python-Alwina.py' – Quellcode des Dashboard-Prototypen
- 'studiengang.json' – gespeicherte Studiendaten

## Voraussetzungen

Für die Ausführung wird benötigt:

- Windows
- Python 3.10 oder neuer

Es werden keine zusätzlichen Python-Pakete benötigt.  
Für die grafische Benutzeroberfläche wird 'tkinter' verwendet.

## Installation und Start

1. Dieses GitHub-Repository herunterladen.

   Dazu auf **Code → Download ZIP** klicken.

2. Die heruntergeladene ZIP-Datei entpacken.

3. Darauf achten, dass sich folgende Dateien im selben Ordner befinden:

   - 'Python-Alwina.py'
   - 'studiengang.json'

4. Eine Eingabeaufforderung bzw. ein Terminal in diesem Ordner öffnen.

5. Das Programm mit folgendem Befehl starten:

   ```bash
   python Python-Alwina.py
